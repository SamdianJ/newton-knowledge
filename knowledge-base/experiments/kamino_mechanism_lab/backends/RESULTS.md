A/B 尾段位置最大差 `2.6840e-7 m`、速度最大差 `1.7030e-6 m/s`，均低于事前窄场景一致性门槛。全时段速度最大差 `6.8834e-5 m/s`。构型中球体受到导轨限制而无法旋转；倾斜轴使导轨双边反力与地面接触不等式耦合。独立几何重算和自由段解析参考支持该最小机械场景的结果。

**终态收敛比例不是物理准确率。** PADMM 的 `r_p/r_d` 是物理单位下的 ADMM 共识/迭代变化残差；DVI 的同名量是锥投影距离和速度违反。两者停止规则和默认迭代日程不同。当前物理轨迹几乎一致而收敛标记比例明显不同，不能由此推导 DVI 更准确、更稳定或更快，也不能把 PADMM 未标记收敛的全部步当物理失败。

完整配置树仅有四处预声明差异：`dynamics_solver`、`sparse_jacobian`、`dynamics.preconditioning`、`dynamics.linear_solver_type`。两份配置都保存 PADMM 与 DVI 子容器，但 backend 选择激活不同算法、迭代和 warmstart 路径；这是配置组比较，不是严格单参数干预。

适用范围仅限固定 Newton 1.7.0、此 CPU 环境、单 world、单被动 prismatic 滑块和一个球-平面接触。没有覆盖接触密集场景、闭环、长时间稳定性、GPU、DVI Schur/稀疏 dynamics 或 PADMM 分支扫描，也没有进行摩擦参数标定。只读内部 `_config` 与 `_contacts_kamino.model_active_contacts` 仅用于固定版本观测，不作为公共 API 承诺。

曲线中的对数纵轴将零值显示在 `1e-12` 下限，仅为可视化；原始数组和分析指标保留真实零值。
