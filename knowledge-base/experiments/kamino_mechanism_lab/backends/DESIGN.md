# PADMM 与 DVI 配置组对照设计

本方案在任何 Newton 运行前制定，等待主代理统一审核冻结。固定 Newton 1.7.0；不修改引擎或旧实验。

采用一个 1 kg、半径 0.1 m 的球形滑块，通过 world-to-body prismatic joint 限制为沿 `(0.6,0,-0.8)` 倾斜直线平移。初始中心 `(0,0,0.35)`，重力驱动下落至 z=0 平面。五个双边约束与接触不等式同时存在；倾斜轴使导轨反力与地面接触响应耦合，比自由落球更适合观察后端差异。质心与 body origin 相同，旋转被关节约束。

A 使用公开 PADMM 默认配置组，B 使用公开 DVI 默认配置组。依赖默认值包含 Jacobian 表示、预条件、线性求解器、warmstart 和迭代日程，不能宣称只改变一个参数。两者都用 Euler、内部碰撞、CPU 非 graph 调度、相同 alpha/gamma/delta。保存完整配置 diff，不以等迭代预算或运行耗时排名。

`protocol-draft.json` 给出了全部场景数值、144 步/0.6 秒、每种设置两个独立进程重复、预先数值门槛和理由。自由飞行前 0.2 秒使用独立解析投影重力参考；接触后独立计算球面穿透、导轨偏离、旋转误差、终态位置速度与总能量。记录两后端各自定义的状态残差，不把同名 `r_p/r_d` 当相同误差，更不把收敛标记当物理正确性。

证据有效性、物理标准和两后端的一致性三层分开。未发现显著差异也可报告；物理标准失败则保留失败及适用边界，不改阈值。最终独立分析必须重新读取 NPZ 计算指标，不复用运行器的最终标量作为真值。

本实验不覆盖闭环、多接触密集系统、GPU、DVI Schur 或稀疏 dynamics、长时间稳定性，也不提供普适摩擦标定结论。闭环/FK 和驱动/reset 由其他 agent 独立处理。
