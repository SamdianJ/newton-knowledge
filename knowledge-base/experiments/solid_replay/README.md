# MuJoCo 与 Kamino 实体轮廓回放

当前31组保存实验、62个A/B变体统一使用与VBD相同的共享WebGL渲染方式。真实场景的方块、球体、四杆连杆按归档尺寸与局部变换绘制，并随原始body_q的XYZ+XYZW位姿运动。地面和关节位置来自实验场景。球面色带是帮助观察转动的表面标记。

无shape的单转子实验没有可恢复的真实物体外形，因此用明确标注的示意转盘和指针表达真实转角；偏心转子臂长采用已记录的COM偏移，宽度/盘半径为展示尺寸。这些图形不作为碰撞表面，不参与动力学，也不补写物理实验结论。四杆原有box几何是否关闭碰撞亦在来源说明中保留。

- 拖动旋转、滚轮缩放、Shift拖动平移，A/B相机与尺度同步。
- 可选3D斜视、正视XZ、侧视YZ和俯视XY；可放大A/B比较。
- 初始场景范围便于看清物体；全轨迹范围展示失稳实验的完整位移，不裁掉原始轨迹。
- 时间滑杆选择原始保存帧，播放没有计算新物理。短实验慢放，标签仍显示原始时间；FK目标序列不冒充物理时间。

几何生成源为`scripts/build_solid_replays.py`、`scripts/replay_geometry_kamino.py`；`geometry.json`保存全部来源路径与SHA256。`scripts/rebuild.py`会重建几何元数据；不会运行仿真。原始report-data、catalog、NPZ、协议和历史分析全部保留。历史实验README里“仅显示坐标系”的文字描述的是原版展示，当前入口已加载此实体回放。
