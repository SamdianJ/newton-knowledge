# 场景探索记录（不混入最终 A/B 结论）

最终比较使用 `cases.json` 中冻结的场景，两侧仅改变声明的干预项。下面记录编写最小场景时遇到的问题；这些不是最终表中的轨迹。

1. 最初的水平硬弹簧链使用 ke=20000、dt=1/120、16 个粒子、0.6 秒。iterations=1 的末端坐标增长到约 -4.07e19 mm，而 iterations=30 仍有限。这是本场景/预算下的发散，不能写成 VBD 对任意大步长无条件正确。主表改用保持一维顺序的垂直链 ke=2000、dt=1/240，以便与可计算的全局线性隐式解定量比较。
2. 只用两个独立三角形、没有任何 bending edge 的自接触场景，在 Windows + Warp 1.18 CPU 的空 edge BVH refit 出现空指针读取。主表使用每张薄片两个三角形及一个内部 bending edge；没有修改 Newton 实现。该现象暂记为环境/最小构造边界，不归结为已定位并修复的上游 bug。
3. 弯曲 pilot 使用 edge_ke=0.01 / 1、阻尼=0.02、结束时刻=1.2 秒，两侧均有大幅摆动，单看终态会产生误导。主表改用 0.01 / 10、相同阻尼=0.1，运行 2 秒并保留完整时间曲线；A/B 的公共设置完全一致。
4. DAT pilot 曾使用粒子半径 5 mm，截断保护的中心位置与带半径接触偏置容易混淆。最终 DAT 行使用半径 0 的质点与解析薄板，明确只评价质点是否穿越板顶；显示的小圆点是可见性标记，不是额外碰撞半径。

这些调整用于让每个实验的问题与量测一一对应，不用于宣称一组参数对所有任务更优。所有正式结论只关联最终保存的脚本、配置与轨迹。
