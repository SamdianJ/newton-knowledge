# Kamino 有界 PD：收敛原因、非饱和跟踪与力限切换

本轮采用三个实验 agent 分工并交叉复核，实际完成 **22 次唯一正式运行、7 组配对案例**。每个设置独立进程重复两次；4 组收敛对照共用同一严格基线，因此不把复用基线重复计数。所有正式运行通过预先冻结的物理门槛，但旧高增益饱和场景的严格 `1e-7` 收敛要求仍未解决。

固定 Newton 1.7.0 / commit `7e75abe28b8d69522bc0b34837aaed2c303dff5a`，CPU、单 world。本轮修改实验和知识库生成源，没有修改 Newton 实现，也没有调整其默认配置。

## 原因判断

| 需要区分的问题 | 证据 | 本轮判断 |
|---|---|---|
| 原实验是否统计错了 | 排除初始未求解 status；旧两次 80 个有效步均仅互补残差超阈；新观测基线的状态与终止结果逐元素匹配旧数据 | 旧 0% 不是占位值或统计读取错误 |
| 是否仅迭代预算不足 | 每步有效迭代从 200 增到 1000，已逐迭代核实；最终残差和轨迹与原基线相同 | 增加到 1000 次未解决该场景的停滞 |
| 是否是停止容差的作用 | 只将互补容差从 1e-7 改成 1e-6，配置收敛从 0% 到 100%；原严格标准重算仍为 0% | 放宽门槛解释了标记改变，不是原精度问题已修复；提前停止会产生细小轨迹变化 |
| 求解器内部发生了什么 | 预定六步的尾 20 次有界变量停止变化；非零对偶校正小于半个 float32 ULP，独立加法也将它舍入掉；三残差独立重算匹配源公式 | 支持当前场景、算术和缩放下的有限精度停滞；不证明通用精度下限或所有 PD 都存在算法缺陷 |
| 是否可通过简单开关修复 | 关闭加速仍 0%；关闭预条件仍 0%，互补残差更大 | 这两个开关未解决原严格要求，不能作为通用调参建议 |

有界行互补残差使用未投影的 `x` 和更新后的 `z`：

```text
r_c = abs((x-lower)*max(z,0) + (upper-x)*max(-z,0))
```

代表第 0 步：`x=0.0450000949204`，投影 `y=upper=0.0449999980628`，`z=-4.39955616`。x 距上界约 `9.68575e-8`，对应 26 个边界 ULP，乘以 |z| 得 `r_c≈4.26130e-7 J`。对偶校正约 `-9.68575e-8`，小于 z 的半 ULP `2.38419e-7`，更新前后 z 不变。投影 y 已准确触界，所以实际饱和力矩正确，而源实现的 x 残差仍未达标。不能把残差改用 y 算成零后声称源停止条件已通过。

## 场景、事前门槛与结果

三个冻结记录分别为 [收敛诊断](../../planning/kamino-pd-2026-10-29/convergence-freeze.json)、[非饱和跟踪](../../planning/kamino-pd-2026-10-29/tracking-freeze.json)、[力限切换](../../planning/kamino-pd-2026-10-29/limit_switch-freeze.json)。它们均早于对应正式运行；失败和观测程序修正没有改变物理门槛。

**收敛诊断：10 次运行。** 保留旧单转子、COM 偏移 0.5 m、有效惯量 1.25 kg·m²、kp=100、kd=2、目标 ±1 rad、力限 ±1 N·m、dt=.005 s、80 步。力矩误差门槛 .002 N·m，速度参考 .002 rad/s，Euler 角位移参考 .001 rad；三个残差阈值与物理门槛分别判断。

| 唯一配置干预 | 配置收敛 | 原严格收敛 | 最大迭代 | 末互补残差中位数 J |
|---|---:|---:|---:|---:|
| 严格基线 | 0% | 0% | 200 | 4.254156e-7 |
| 预算 1000 | 0% | 0% | 1000 | 4.254156e-7 |
| 互补容差 1e-6 | 100% | 0% | 16 | 4.256395e-7 |
| 关闭加速 | 0% | 0% | 200 | 4.255318e-7 |
| 关闭预条件 | 0% | 0% | 200 | 4.601580e-4 |

实际 ±1 N·m 力矩及运动均通过冻结门槛。详见 [诊断结果](../../experiments/kamino_pd_lab/convergence/RESULTS.md)。

**非饱和跟踪：8 次运行。** COM 位于 Y 转轴，I=1 kg·m²、kp=25、kd=10、有限力限 10 N·m；dt=.005 s，800 步、4 s。独立参考从隐式 PD 方程求解，不用连续 PD 的前向 Euler 替代，也不裁剪参考力矩。实际与参考的力限裕量都必须 ≥4 N·m。全瞬态角/速度/力矩参考误差门槛分别 .0005 rad、.001 rad/s、.002 N·m。

- 正负镜像阶跃在 2 s 反向。端点误差约 `1.105e-4 rad`、端点速度 `5.009e-4 rad/s`；常目标段能量无正增量，满足预定镜像、稳定性和非饱和门槛。
- 正弦幅值 .1 rad、频率 .5 Hz，两模式收到相同位置/速度目标。POSITION_VELOCITY 的末周期 RMS `0.0193778 rad`，POSITION 为 `0.0664529 rad`，改善约 70.84%。各自均吻合独立离散参考；POSITION 忽略速度目标但保留 kd 阻尼，符合源码语义。
- 8 次运行的严格收敛标记均为 100%。这些不同惯量、增益与幅值的场景不是逐因素拆解旧场景停滞原因的实验，不能将其成功反推到旧高增益饱和场景。

详见 [跟踪结果](../../experiments/kamino_pd_lab/tracking/RESULTS.md)。

**力限切换：4 次运行。** COM 在轴上、I=1、kp=20、kd=2；目标正负 .1 rad，六阶段各 20 步。A 按 `.25→4→.25→.25→4→.25 N·m` 切换，B 固定 .25 N·m。每次修改使用 `notify_model_changed(JOINT_DOF_FORCE_PROPERTIES)`，仅测试有限正值修改、不增删有界行。

- A 每阶段 20 个样本均实现正饱和→释放→重入→反饱和→释放→重入。
- 四次修改均在紧接的求解步生效，允许滞后门槛为 0 步；内部冲量界匹配 `dt*limit`，最大误差约 `4.47e-10 N·m·s`。
- 通知前后状态差为零，驱动路径和一条 effort row 保持不变。最大力矩、角位移、速度参考误差分别约 `2.66e-6 N·m`、`1.40e-7 rad`、`9.93e-7 rad/s`。
- 本场景 A/B 严格收敛均为 100%，最多 20/9 次迭代。仍不外推零/无限力限、路由结构变化、GPU 或复杂接触。

详见 [切换结果](../../experiments/kamino_pd_lab/limit_switch/RESULTS.md)。

## 观测程序问题与证据保留

两次失败尝试已保留并排除出 22 次正式运行：收敛组首次包装器把 CPU `.numpy()` 共享视图当成旧 status 快照；跟踪组首次将协议的预条件意图映射到了错误的 API 配置归属。前者改为复制观测标量；后者明确记录协议标签到 `Config.dynamics.preconditioning=True` 的映射。二者均在继续运行前审核，不改变场景或物理阈值，也不能解释旧数据中的 0% 结果。

收敛组还将无效容量尾部从导出文件中排除，仅保存六个活跃列；先前完整容量基线保留，按相同活跃行归一后比较。不同观测程序 SHA 明确记录，不假定其相同。所有正式原始 NPZ、配置、协议/runner 副本、源码核验和失败记录均保留。

## 剩余边界

1. 原高增益饱和场景严格收敛仍未解决。需要匹配的更高精度或更稳健数值更新对照，才能判断具体实现修复的效果；当前没有修改 Newton 算法。
2. 尚未逐项分离惯量/COM 偏移、增益、目标幅值、rho/eta、缩放和时间步对停滞的贡献，也未形成通用容差建议。
3. 非饱和跟踪只覆盖给定阶跃和 .5 Hz 正弦，不代表全带宽、全增益或多关节性能；切换只覆盖有限正值力限且有公开通知。
4. 多关节、接触、GPU/graph、多 world、长时间稳定性及论文基准仍未覆盖。
